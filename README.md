# wpress-extractor Windows/Mac
A simple go app that allows you to extract .wpress files created by the awesome All-in-one-Wp-Migration Wordpress plugin

## Quickstart
1. Install [mise](https://mise.jdx.dev/installing-mise.html)
2. Trust the repository: `mise trust`
3. Install mise dependencies: `mise install`
4. Extract a `.wpress` file: `mise run extract <.wpress-file>`
5. Zip the extracted contents
